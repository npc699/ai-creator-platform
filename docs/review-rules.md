# 内容审核与质量评分规则

## 安全审核类别

模型返回类别必须使用稳定英文枚举，前端再映射为中文标签。

- `pornography`：涉黄、色情交易、性暗示引流。违规示例：招嫖联系方式、色情资源售卖、露骨性描写。合规边界：健康科普、文学中非露骨情节、反诈提醒。
- `gambling`：赌博、博彩、赌球、赌资交易。违规示例：彩票平台引流、下注教程、刷流水套利。合规边界：反赌科普、法律新闻、风险提示。
- `drugs`：毒品制作、购买、吸食、美化。违规示例：购买渠道、制作配方、吸食体验炫耀。合规边界：禁毒宣传、医学合规用药、新闻报道。
- `political_sensitive`：政治谣言、煽动性政治攻击、涉政敏感动员。违规示例：未经证实的涉政谣言、煽动对立、组织非法行动。合规边界：公开政策解读、历史知识、理性评论。
- `harassment`：人身攻击、侮辱、歧视、网暴引导。违规示例：点名辱骂、地域/性别歧视、煽动围攻。合规边界：产品差评、事实陈述、非攻击性批评。
- `vulgar`：低俗猎奇、恶俗擦边、未成年人不适宜表达。违规示例：低俗标题党、恶俗身体羞辱、擦边诱导点击。合规边界：幽默表达、非低俗生活吐槽。
- `misinformation`：明显虚假信息、医疗/金融等高风险误导。违规示例：虚假疗效承诺、投资稳赚、伪科学恐吓。合规边界：经验分享、带来源的科普、明确不构成建议的观点。

## 风险等级

- `high`：明确违法违规、诱导交易、教学实施、煽动伤害或明显高危内容，系统直接拦截。
- `medium`：存在较强风险或事实不确定，系统标记 `FLAGGED`，提示用户修改或后续复核。
- `low`：轻微不当、措辞粗糙或质量边界问题，允许发布并提示优化。
- `none`：未发现明显风险。

## 质量评分维度

每项 0-10 分，综合分 0-100 分。

- 标题吸引力 `titleAppeal`，权重 15%。好：准确、有信息增量、有阅读动机；差：标题党、空泛、与正文不符。
- 内容完整度 `completeness`，权重 25%。好：主题完整、论据充分、有结论；差：只有片段、缺少关键步骤、结尾突兀。
- 逻辑结构 `structure`，权重 20%。好：层次清晰、段落推进自然；差：跳跃、重复、主次混乱。
- 可读性 `readability`，权重 15%。好：表达流畅、术语解释充分；差：病句多、堆砌、难以理解。
- 原创性 `originality`，权重 15%。好：有独立观点、案例或经验；差：模板化、复述常识、疑似拼接。
- 配图相关性 `imageRelevance`，权重 10%。好：图片帮助理解正文；差：无关图、营销图、正文需要图却完全没有图。
